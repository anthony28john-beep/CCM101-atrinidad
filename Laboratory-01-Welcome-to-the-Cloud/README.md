# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory introduced me to a Linux cloud environment and the basic skills needed to work with a cloud-based Linux system. I used the KillerCoda Linux Playground to explore Ubuntu, create a user account, investigate the system environment, and organize my workspace.

## Objectives

The objectives of this laboratory were to:

* Launch and explore an Ubuntu Linux cloud environment.
* Create and access a new Linux user account.
* Identify important system information such as the Linux distribution, kernel version, CPU, memory, and disk space.
* Create an organized workspace using directories and files.
* Create a GitHub repository for my cloud computing portfolio.
* Document my laboratory activities and learning progress.

## Activities Performed

1. Launched an Ubuntu 24.04 Linux Playground using KillerCoda.
2. Verified that the Linux terminal was functioning correctly.
3. Created a new user account with a home directory, Bash shell, and sudo privileges.
4. Logged in to the new user account.
5. Collected information about the Linux operating system and hardware.
6. Created the `system-information.md` file.
7. Created the `Notes`, `Reports`, and `Screenshots` directories.
8. Created the `about-me.md` file inside the `Notes` directory.
9. Created a public GitHub repository for my CCM101 cloud computing portfolio.
10. Organized the Laboratory 01 files in the required folder structure.

## Linux Commands Used

The following Linux commands were used during the laboratory:

```bash
whoami
pwd
hostname
sudo adduser
sudo usermod
su
cd
mkdir
ls
cat
nano
uname
lscpu
free
df
```

These commands were used to identify the current user and working environment, manage users, navigate directories, create files and folders, and collect system information.

## Skills Learned

Through this laboratory, I learned how to:

* Navigate and work with a Linux terminal.
* Manage Linux user accounts and permissions.
* Use basic Linux commands.
* Collect information about a Linux system.
* Create and organize files and directories.
* Work with Markdown files.
* Use a cloud-based Linux playground.
* Create and organize a GitHub repository.
* Document technical activities and maintain a cloud computing portfolio.

Overall, this laboratory helped me develop a foundation in Linux and cloud computing that I can build upon throughout the semester.
