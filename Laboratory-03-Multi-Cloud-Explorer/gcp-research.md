# Google Cloud Platform (GCP) Research

## Brief Overview
Google Cloud Platform (GCP) is a suite of cloud computing services offered by Google. Built on the same high-speed internal infrastructure that Google uses for products like Google Search and YouTube, GCP delivers high-performance compute, storage, data analytics, and machine learning solutions.

## Global Infrastructure
GCP infrastructure is designed for high throughput and low latency:
* **Regions:** Specific geographical locations where resources are hosted.
* **Zones:** Deployment areas within a region that represent isolated fault domains.
* **Global Fiber Network:** Google operates its own private subsea and terrestrial global fiber-optic network connecting its data centers.

## Cloud Management Console
The Google Cloud Console is an intuitive web user interface designed to manage GCP resources, view application logs, set up projects, manage API keys, and track cloud spending in real time.

## Four (4) Core Services
1. **Google Compute Engine (GCE):** Provides customizable virtual machines running on Google's infrastructure.
2. **Google Cloud Storage (GCS):** Unified object storage offering high availability, durability, and global accessibility.
3. **Google Kubernetes Engine (GKE):** Managed environment for deploying, managing, and scaling containerized applications using Kubernetes.
4. **Cloud IAM:** Unified access control for project resources with granular role-based permissions.

## Three (3) Advantages
* **Leader in Data Analytics & AI:** Best-in-class tools for machine learning, artificial intelligence, and big data processing (BigQuery, Vertex AI).
* **Native Container Support:** Superior, native Kubernetes support as the original creator of Kubernetes.
* **High-Performance Global Network:** Utilizes Google's private global fiber network for superior speed and low latency.

## Typical Enterprise Use Cases
* Modernizing applications using containers and microservices via Kubernetes.
* Large-scale data processing, real-time analytics, and machine learning model training.
* High-performance computing for web-scale applications.
