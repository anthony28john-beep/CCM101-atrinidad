# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a leading cloud computing service launched by Microsoft in 2010. It provides a broad suite of cloud services including compute, analytics, storage, and networking, designed for building, testing, deploying, and managing applications through Microsoft-managed data centers.

## Global Infrastructure
Azure has a global presence built around a robust network architecture:
* **Regions:** Geographic areas hosting a set of data centers connected through a dedicated low-latency network.
* **Availability Zones:** Unique physical locations within an Azure region featuring independent power, cooling, and networking.
* **Geography Groups:** Broad regions typically containing two or more Azure Regions to preserve data residency and compliance boundaries.

## Cloud Management Console
The Azure Portal is a web-based, unified console that provides an alternative to command-line tools. It allows users to build, manage, and monitor everything from simple web apps to complex cloud deployments using customizable dashboards.

## Four (4) Core Services
1. **Azure Virtual Machines:** On-demand, scalable virtual machines providing Infrastructure as a Service (IaaS).
2. **Azure Blob Storage:** Scalable object storage solution optimized for storing massive amounts of unstructured data.
3. **Azure Virtual Network (VNet):** Enables secure communication between Azure resources, the internet, and on-premises networks.
4. **Microsoft Entra ID (formerly Azure Active Directory):** Cloud-based identity and access management service.

## Three (3) Advantages
* **Seamless Microsoft Integration:** Unmatched compatibility with Windows Server, Active Directory, Office 365, and .NET.
* **Hybrid Cloud Dominance:** Industry-leading hybrid cloud capability using services like Azure Arc.
* **Enterprise Licensing Flexibility:** Existing Microsoft software licenses can often be reused on Azure via Hybrid Benefit discounts.

## Typical Enterprise Use Cases
* Migrating traditional Windows Server and SQL Server workloads to the cloud.
* Enterprise hybrid cloud deployments linking on-premises data centers to the cloud.
* Large enterprise identity management and access governance.
