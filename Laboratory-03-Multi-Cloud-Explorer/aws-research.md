# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is a comprehensive, evolving cloud computing platform provided by Amazon. Launched in 2006, it offers over 200 fully featured services from data centers globally, enabling businesses to scale applications securely and cost-effectively.

## Global Infrastructure
AWS operates a global network of hardware and data center infrastructure divided into Regions and Availability Zones (AZs).
* **Regions:** Geographic areas containing multiple, isolated locations.
* **Availability Zones (AZs):** Discrete data centers with redundant power, networking, and connectivity within an AWS Region.
* **Edge Locations:** Points of presence (PoP) worldwide used for content delivery networks (CloudFront) to reduce latency.

## Cloud Management Console
The AWS Management Console is a web-based administrative portal used to manage AWS resources, monitor infrastructure, configure security rules, and view billing details through an intuitive graphical user interface.

## Four (4) Core Services
1. **Amazon EC2 (Elastic Compute Cloud):** Provides scalable virtual computing capacity (virtual machines) in the cloud.
2. **Amazon S3 (Simple Storage Service):** Offers highly scalable, secure, and durable object storage for data and backups.
3. **Amazon VPC (Virtual Private Cloud):** Allows users to provision a logically isolated section of the AWS Cloud for networking.
4. **AWS IAM (Identity and Access Management):** Controls secure access to AWS services and resources for users and roles.

## Three (3) Advantages
* **First-Mover Advantage & Ecosystem:** Offers the largest service portfolio and deepest functionality in the market.
* **Scalability and Performance:** High reliability and global infrastructure footprint allowing seamless auto-scaling.
* **Extensive Documentation:** Massive community support, extensive documentation, and vast third-party tool integration.

## Typical Enterprise Use Cases
* Host high-traffic web and mobile applications with auto-scaling requirements.
* Enterprise data warehousing, big data analytics, and data lake storage.
* Disaster recovery and global backup infrastructure.
